Rules:

- Never edit a migration that has been applied to a shared environment. Add a new one.
- Enum values are added with `alter type ... add value`, never by recreating the type.
- Every foreign key column gets an index.
- Tables exposed to end users get RLS enabled in the same migration that creates them,
  or in the RLS migration of the same phase. Deny by default; add SELECT policies deliberately.
- Production migrations run only through the approved pipeline (see `docs/adr/ADR-012-api-deployment.md`),
  never from a developer machine.
