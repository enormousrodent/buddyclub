# Interest photos

One photo per interest, named `<interest id>.jpg` (for example `books.jpg`, `dog_walking.jpg`).
List the id in `components/interest-art.tsx` `INTEREST_PHOTOS` once the file exists. The tile
renders it as duotone in its own colour, so shoot or generate in black and white with the subject
small and the bottom-left quarter empty. Suggested size 1200x800, under 200 KB.
